07

Architectural rationale

Dependency inversion
Use cases depend on repository interfaces, never concrete adapters. Swapping in-memory repos for Postgres requires zero changes to business logic.
No SDK leaks
The evaluation pipeline imports only repository.AIGateway, never any provider SDK. Provider identity is a single bootstrap-time decision.
Concurrency safety
All in-memory repositories hold a sync.RWMutex. Stage 2 goroutines are deadline-aware: any upstream context cancellation propagates via ctx.Done().
HTMX over SPA
Faculty missing-work alerts use hx-trigger="every 30s". Server stays the single source of truth — no JS build pipeline or hydration complexity.
Testability
StubAIGateway is deterministic and rule-based. The full 4-stage pipeline — concurrency, guardrails, weighted aggregation — runs in tests with zero network I/O.
Security posture
Non-root container user appuser:10001. Role gating sits before all controllers. Session extraction is a distinct middleware concern, not controller logic.
