# Project 8: Human-AI Co-Learning Agent

## Problem Statement

Traditional educational management platforms effectively store student submission records, assignment marks, and project grades, but they lack automated analytical tools to convert raw assessment data into actionable pedagogical insights. Educators currently spend substantial time manually grading submissions and attempting to gauge topic-specific student comprehension, often missing early indicators of concept misunderstanding or incomplete submissions. Concurrently, students frequently lack a consolidated interface to track real-time assessment status, grades, and personalized diagnostic feedback. There is a need for an intelligent dual-interface agent that automates assessment evaluation, calculates subject-level comprehension metrics for faculty, and provides students with clear visibility into their submission workflows and performance feedback.

## Objectives

1. Develop an AI-Driven Automated Evaluation Engine:
   - Design and integrate an evaluation agent within the faculty interface that analyzes individual student submissions to quantify topic mastery and compute a percentage-based measure of concept understanding per subject.

2. Build a Dual-Role Portal Architecture:
   - Implement two secure, role-specific interfaces—a Student Phase for managing submission uploads, viewing marks, and receiving feedback; and a Faculty Phase for monitoring submission completeness, tracking missed assessments, and viewing aggregated quality metrics.

3. Establish Real-Time Performance Analytics and Diagnostic Feedback:
   - Create a reporting module that alerts faculty to overdue or missing assessments, highlights learning gaps across individual student profiles, and delivers targeted automated feedback to students to support continuous academic improvement.
