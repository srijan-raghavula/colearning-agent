# Planning Context

Lightweight non-code context for product direction and execution.

## Purpose

- Keep user stories in one place.
- Keep feature plans concise and implementation-ready.
- Make context easy for any AI agent platform to parse and use.

## Structure

- `user-stories.md` → prioritized stories with acceptance criteria.
- `features/` → one file per feature plan.
- `templates/feature-plan.md` → plan template for consistency.
