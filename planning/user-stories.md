# User Stories

## STU-001 - Upload Assessment Submission
- **Role**: Student
- **Need**: Upload assignment/project files for a subject assessment.
- **Value**: Ensure submissions are tracked and available for grading.
- **Acceptance**:
  - Student can submit a file for a chosen assessment.
  - System stores submission status as `submitted`, `late`, or `missing`.

## STU-002 - View Marks and Feedback
- **Role**: Student
- **Need**: View marks and AI-generated feedback per submission.
- **Value**: Understand performance and improve weak topics.
- **Acceptance**:
  - Student sees score and mastery percentage.
  - Feedback includes topic-specific improvement suggestions.

## FAC-001 - Track Completion and Missing Work
- **Role**: Faculty
- **Need**: View submitted/missing assessments for each student.
- **Value**: Identify at-risk students early.
- **Acceptance**:
  - Faculty dashboard lists submission completeness by subject.
  - Missing or overdue work is clearly flagged.

## FAC-002 - Monitor Subject-Level Comprehension
- **Role**: Faculty
- **Need**: View aggregated topic mastery per subject.
- **Value**: Target teaching interventions effectively.
- **Acceptance**:
  - Dashboard shows topic-level average mastery percentages.
  - Low-mastery topics are highlighted for follow-up.
